# Elfrey Scene Browser

Просмотр **всех сцен** из установленных модулей Foundry VTT — включённых и выключенных, — а также из
паков-приключений, паков системы, компендиумов мира и самого мира. Дерево источников, поиск, фильтры,
превью и импорт в один клик. Только для мастера (GM). Foundry VTT v13 (основная цель) и v14.

*Browse every Scene shipped by installed modules (active or not) and by adventure packs, the active system,
world compendiums and the world itself. Tree, search, filters, previews, one-click import. GM only. Foundry
VTT v13 and v14.*

## Что умеет

- **Все сцены сразу.** Сцены мира и паки включённых пакетов читаются живьём; сцены выключенных модулей
  модуль читает сам, прямо из файлов библиотек, и складывает в кэш.
- **Сцены из приключений.** Многие модули упаковывают сцены не отдельным Scene-паком, а внутрь документа
  Adventure. Такие сцены тоже видны: узел «модуль → приключение → папки → сцены».
- **Дерево и поиск.** Дерево «источник → пакет → папки → сцены», поиск по имени/паку/пакету с раскрытием
  веток, множественный выбор узлов (обычный клик — только выбранный, Ctrl/Cmd-клик — добавить).
- **Фильтры и сортировка.** Статус источника, тип сетки, размер в клетках, содержимое (стены/токены/свет/
  заметки), система; сортировка по имени, пакету, размеру, дате, числу стен.
- **Карточки с превью.** Миниатюра, при её отсутствии — фон сцены; размеры в пикселях и клетках, счётчики.
- **Действия.** Открыть/активировать (сцены мира), импортировать и «импортировать и открыть», показать в
  компендиуме, изображение, копировать UUID/путь, перетаскивание в сайдбар. Импорт создаёт вложенные папки
  «модуль → приключение → внутренняя папка». **Сцену выключенного модуля можно импортировать не включая
  модуль** — у модуля есть её полный JSON.

## Как это работает

Данные включённых пакетов берутся из штатного API (`game.packs`, `game.scenes`). Библиотеки выключенных
модулей — это файлы LevelDB на диске; сервер Foundry v13 отдаёт их статикой, и модуль читает их в Web
Worker, а результат кэширует в `Data/elfrey-scene-browser/`. На v14 сервер такие файлы не отдаёт, поэтому
там выключенные модули доступны только из ранее собранного кэша — его собирает отдельный скрипт
`tools/build-cache.mjs` (см. ниже), который мастер запускает сам.

## Кэш для Foundry v14 (и офлайн)

На v14 браузер не может прочитать файлы библиотек выключенных модулей. Соберите кэш заранее скриптом —
он читает паки прямо из файлов, без запуска Foundry и без зависимостей:

```sh
node tools/build-cache.mjs --data /путь/к/папке-данных-foundry
```

Чтобы на v14 ещё и **импортировать** сцены из выключенных модулей, добавьте `--full-scenes` — скрипт запишет
полные документы сцен, и импорт возьмёт их напрямую (иначе на v14 импорт из выключенного модуля недоступен —
сервер не отдаёт файлы библиотек):

```sh
node tools/build-cache.mjs --data /путь/к/папке-данных-foundry --full-scenes
```

Подробности и флаги — в [tools/README.md](tools/README.md). После прогона нажмите в браузере «Обновить».

## Установка

Manifest URL:

```
https://github.com/Elfrey/elfrey-scene-browser/releases/latest/download/module.json
```

В Foundry: *Add-on Modules → Install Module* → вставьте ссылку. Включите модуль в мире, откройте вкладку
«Сцены» или «Компендиумы» и нажмите кнопку **«Браузер сцен»**. При первом запуске нажмите **«Индексировать»**,
чтобы прочитать библиотеки выключенных модулей.
