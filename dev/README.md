# Инструменты разработчика

Ничего из этой папки модуль во время работы не использует.

## check-reader.mjs — самопроверка ридера LevelDB

Читает каждый Scene-пак папки данных нашим ридером (`scripts/leveldb/`) и, для сравнения, через `classic-level`
из установки Foundry, затем сверяет сцены, папки и счётчики встроенных документов.

```sh
nvm use 22   # или 24
node dev/check-reader.mjs --data /path/to/data-v13 --copy-locked
```

| Флаг | Назначение |
| --- | --- |
| `--data <dir>` | папка данных Foundry (та, что содержит `Data/`) — обязательный |
| `--foundry <dir>` | папка программы Foundry с `node_modules/classic-level`; по умолчанию ищется `fvttNN` рядом с папкой данных |
| `--only <id>` | только паки одного пакета |
| `--copy-locked` | паки, открытые запущенным миром, копировать во временную папку для эталонного чтения (наш ридер всегда читает оригиналы) |
| `--embed` | собирать встроенные документы для всех сцен и сверять их число и уникальность id (память: до ~2 ГБ на больших паках) |
| `--no-verify` | не проверять контрольные суммы |
| `--limit N` | первые N паков |

Код возврата 1 — есть расхождения или ошибки чтения; подробности печатаются в конце.

## smoke-http.mjs — индексатор против живого сервера

Прогоняет браузерную часть индексатора из Node: `probeSignature()` (CURRENT / MANIFEST / HEAD по HTTP) и чтение
пака воркером `scripts/leveldb/worker.js` (через `worker-shim.mjs`, который подменяет `self` браузерного воркера).
FilePicker (листинг папок, запись кэша) требует сессии Foundry и здесь не проверяется.

```sh
node dev/smoke-http.mjs https://localhost:30013 modules/ag-dnd2024/packs/dmg-scenes modules/czepekumaps-master/packs/czepekumaps-sc
```

## test-cache.mjs — проверка логики кэша

Юнит-проверка `scripts/cache.js` на заглушках FilePicker/fetch: выбор самого свежего файла на пак, учёт вытесненных
и битых файлов, запись нового файла и повторная загрузка.

```sh
node dev/test-cache.mjs
```

## browser-index-test.mjs — индексатор в настоящем браузере

Полный прогон индексатора против живого мира Foundry через Chrome DevTools Protocol: логин мастером,
открытие окна, индексация, отчёт. Так были найдены две ошибки фазы 2 (см. историю PLAN.md). Требует
одноразовую копию папки данных (в мире `resetKeys:true`, модуль включён), запущенный сервер на порту 30213
и headless Chrome с `--remote-debugging-port=9222 --enable-unsafe-swiftshader`. Константы `BASE`/`GM`
правятся под инстанс (`GM` — `_id` мастера из `getJoinData`).
