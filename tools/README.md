# tools/build-cache.mjs — сборка кэша сцен вне Foundry

Скрипт читает Scene- и Adventure-паки папки данных Foundry прямо из файлов и пишет кэш модуля. Нужен там,
где браузерная индексация недоступна — прежде всего на **Foundry v14**, где сервер не отдаёт клиенту файлы
библиотек. На v13 тоже работает.

Использует только чистый ридер модуля (`scripts/leveldb`): без нативных модулей, без `classic-level`, без
`npm install`. Базы не блокируются, поэтому скрипт можно запускать при работающем мире (и для включённых, и
для выключенных модулей).

```sh
node tools/build-cache.mjs --data /путь/к/папке-данных-foundry
```

| Флаг | Назначение |
| --- | --- |
| `--data <dir>` | папка данных Foundry (та, что содержит `Data/`) — обязательный, можно указать несколько раз |
| `--out <name>` | имя папки кэша внутри `Data/` (по умолчанию `elfrey-scene-browser`; поменяйте, если меняли настройку «Папка кэша» в модуле) |
| `--full` | перечитать все паки, игнорируя проверку «не изменилось с прошлого раза» |
| `--quiet` | печатать только итог |

Запускать можно любым Node.js. После прогона откройте «Браузер сцен» и нажмите «Обновить» (круговая
стрелка), чтобы модуль перечитал кэш.

**Как узнать путь к папке данных.** Это каталог из параметра `--dataPath` при запуске Foundry (в нём лежат
`Data/`, `Config/`, `Logs/`). Например, для сборки на Node это та папка, что вы передаёте в `--dataPath`; у
десктопного приложения путь виден в *Configuration → User Data Path*.

**Актёры.** С `--full-scenes` рядом с каждой сценой приключения пишется файл `<sceneId>.actors.json` с полными документами актёров, на которых ссылаются токены сцены. При импорте сцены модуль создаёт этих актёров (сохраняя их id, уже существующих не трогает) в папке актёров, чтобы токены на сцене работали.
